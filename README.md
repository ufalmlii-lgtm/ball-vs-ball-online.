BALL vs BALL Online starter

1. Upload semua file/folder ini ke satu repository GitHub.
2. Di Render pilih New > Web Service dan hubungkan repository.
3. Runtime: Node; Build Command: npm install; Start Command: npm start.
4. Deploy, lalu buka URL Render. Teman membuka URL yang sama dan memasukkan kode ruangan.

Ini demo online dasar untuk menguji ruangan, posisi, dan HP. Ini bukan versi final game 3D dan belum memiliki akun, penyimpanan achievement, atau semua skill.
